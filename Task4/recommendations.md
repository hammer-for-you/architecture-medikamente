# Рекомендации по устранению узких мест



### Инфраструктура

- Кластеризация БД - высокий приоритет

- Внедрение Kubernetes - высокий приоритет

- Внедрение системы алертинга



### Программное обеспечение

- Отказ от файлового режима работы - высокий приоритет

- Организация команды тестирования, внедрение баг-трекера



### Интеграция

- Разработка внешнего API для интеграции с партнёрами

- Проверка хэшей файлов при передаче

- Внедрение API Gateway



### Безопасность

- Внедрение шифрования персональных и медицинских данных - высокий приоритет

- Внедрение контроля доступа - высокий приоритет

- Журналирование и аудит действий с данными

- Анонимизирование медицинских данных

- Разработка внутренних регламентов работы с чувствительными данными
  
  

### Персонал

- Найм недостающих сотрудников: frontend-разработчиков, специалистов по ИБ, тестировщиков - высокий приоритет

- Разъяснение преимуществ новой системы, обучение, привлечение сотрудников к обсуждению и разработке новых бизнес-процессов

- Сбор обратной связи от сотрудников



### Процессы

- Внедрение процессов CI/CD - высокий приоритет

- Настройка автоматического снятия бэкапов с баз данных

- Автоматизация труда сотрудников
